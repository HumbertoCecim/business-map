## Abrir e experimentar

Abra <http://127.0.0.1:3091/demo>. O processo local foi deixado ativo. Se estiver encerrado, execute na raiz:

```powershell
node cloud/widget/ui-test-server.mjs
```

O menu da demo abre o site e o widget inline, alterna entre dois negócios fictícios e adiciona/remove uma área para testar atualizações. No desktop, arraste pela alça pontilhada. Explore pelas setas, volte pelo breadcrumb e use **Reset layout** para restaurar somente o nível atual. **Fit map** enquadra o conjunto. EN/PT alterna textos da interface sem traduzir conteúdo.

Dados fictícios ficam em memória nesse processo. Preferências de apresentação ficam no navegador, separadas do mapa, com fallback em memória se storage for negado. Essa demo não é uma migração do armazenamento cloud. Importação, conta e autenticação não fazem parte do harness.

## Alterações e verificações

Tipografia, contraste, espaçamento, seleção e títulos foram refinados mantendo identidade, centro, contexto lateral e cinco níveis. Posições absolutas e viewport são isolados por negócio/board/foco, reconciliados por ID. Arrastar não executa comandos, muda revisão ou altera hierarquia. Centro/propostas ficam fixos; celular/widget não arrastam. A altura inline permanece limitada. Corrigida também a colisão de keys que deixava editores antigos no inspetor.

Checks finais executados na ponta desta branch, registrados na PR e no workpad:

```powershell
$env:BUSINESS_MAP_TEST_BROWSER='C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
npx --yes pnpm@10.33.1 --dir cloud test:ui
npx --yes pnpm@10.33.1 --dir cloud typecheck
npx --yes pnpm@10.33.1 --dir cloud test
npx --yes pnpm@10.33.1 --dir cloud build
npm test
npm run typecheck
git diff --check
```

Cobertura: arraste/atualização/recarga, retorno ao nível, dois negócios com IDs repetidos e revisões distintas, reset isolado, storage negado, inclusão/remoção, cliques/teclado/zoom, rascunhos mobile, claro/escuro, resize desktop→mobile, altura e viewport do widget, revisão de propostas e editor único. Os testes de navegador usam Edge real com fixtures fictícias. Smoke adicional sem interceptação de APIs validou edição→reload→undo, troca de negócio e revisão inline na demo.

Limites: o host local usa a ponte oficial MCP Apps, mas não valida integração no ChatGPT real, OAuth ou persistência cloud. A inspeção inicial foi feita antes das edições em `88bef27`; é evidência histórica, não um check da nova versão. Avisos preexistentes de depreciação `inputValidator` e sourcemap de `standardwebhooks` não impediram os checks.
